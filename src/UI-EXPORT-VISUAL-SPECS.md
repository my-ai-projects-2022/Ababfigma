# 面包工坊 - 页面 UI 视觉稿导出文档

## 📋 文档说明

本文档包含**面包工坊**所有 14 个页面的完整 UI 视觉规范，适用于设计师、前端开发人员进行页面开发和还原。

**技术栈**: Uni-App + Vue3 + TypeScript + Vite  
**设计基准**: 375×812pt (iPhone 13)  
**设计系统**: 8pt 网格系统

---

## 🎨 全局设计 Token

### 颜色变量
```css
/* 主色系 */

```
