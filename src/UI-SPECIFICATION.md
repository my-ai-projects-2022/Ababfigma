## 项目概述

**项目名称**: 面包工坊 (Bread Workshop)  
**项目类型**: 移动端本地面包订购管理工具  
**目标平台**: 移动端 (375×812pt - iPhone 13标准)  
**设计理念**: 双角色切换（用户端 + 主理人端）

## 响应式设计

### 断点
```css
移动端: 375px (基准)
平板: 768px
桌面: 1024px+
```

### 适配策略
1. **移动端优先**: 所有设计以375px为基准
2. **弹性布局**: 使用 Flexbox 和 Grid
3. **相对单位**: 使用 rpx (Uni-App) 或 rem
4. **安全区域**: 考虑刘海屏和底部安全区域

## 动画和过渡

### 通用过渡
```css
transition: all 0.2s ease;        /* 快速交互 */
transition: all 0.3s ease-out;    /* 常规动画 */
```

### 关键动画
1. **弹窗出现**: scale + fadeIn (0.3s)
2. **页面切换**: slideIn (0.25s)
3. **按钮点击**: scale(0.95)
4. **卡片hover**: translateY(-2px) + shadow

### 动画时机函数
```css
ease-in: 加速进入
ease-out: 减速退出
ease-in-out: 两端缓动
cubic-bezier(0.34, 1.56, 0.64, 1): 弹性效果
```

## 状态处理

### 加载状态
- **全屏加载**: 居中显示加载动画
- **局部加载**: 骨架屏或加载占位符
- **按钮加载**: 禁用 + 加载图标

### 空状态
```
┌─────────────────────────────┐
│                              │
│        📦 (大图标)          │
│                              │
│      暂无数据                │
│      点击添加内容            │
│                              │
└─────────────────────────────┘
```

### 错误状态
- **网络错误**: 显示重试按钮
- **权限错误**: 提示登录或授权
- **数据错误**: 友好的错误提示

## 无障碍设计

### 对比度要求
- **正文**: 对比度 ≥ 4.5:1
- **大号文本**: 对比度 ≥ 3:1
- **图标**: 对比度 ≥ 3:1

### 触摸目标
- **最小尺寸**: 44×44px
- **推荐尺寸**: 48×48px
- **间距**: 至少8px

### 文本可读性
- **行高**: 1.5 倍字号
- **段落间距**: 1em
- **最大行宽**: 75 字符

---

## 开发注意事项

### Uni-App 特殊处理
1. **单位使用**: rpx 自动适配不同屏幕
2. **导航栏**: 使用 `navigationStyle: custom` 自定义
3. **状态栏**: 使用 `uni.getSystemInfoSync()` 获取高度
4. **底部安全区**: 使用 `env(safe-area-inset-bottom)`

### 性能优化
1. **图片优化**: 使用 webp 格式，懒加载
2. **列表优化**: 虚拟滚动，分页加载
3. **动画优化**: 使用 transform 和 opacity
4. **缓存策略**: 合理使用本地存储
