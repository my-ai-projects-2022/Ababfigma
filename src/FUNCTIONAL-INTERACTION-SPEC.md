# 1. 项目概述

## 1.1 产品定位

**面包工坊**是一个连接本地面包制作爱好者（主理人）和面包消费者的移动端订购管理平台。

### 核心价值
- **用户端**: 发现附近优质主理人，轻松订购新鲜面包
- **主理人端**: 管理订单、商品和销售数据，提升经营效率

### 业务特点
- 📍 基于地理位置的主理人推荐
- 🏪 一对多模式（一个主理人可服务多个用户）
- 🔄 双角色无缝切换
- 📦 本地化订单管理

---

## 1.2 功能模块总览

```
面包工坊
├── 用户端
│   ├── 首页（主理人列表）
│   ├── 主理人详情
│   ├── 订单管理
│   ├── 个人中心
│   ├── 我的收藏
│   ├── 我的喜欢
│   ├── 地址管理
│   ├── 问题反馈
│   └── 资料编辑
│
└── 主理人端
    ├── 主理人中心
    ├── 订单管理
    ├── 面包管理
    └── 我的成就
```

# 2. 角色与权限

## 2.1 角色定义

### 2.1.1 游客（未登录用户）
**权限**:
- ✅ 浏览主理人列表
- ✅ 查看主理人详情
- ✅ 查看面包信息
- ❌ 下单购买
- ❌ 收藏/喜欢
- ❌ 查看订单
- ❌ 访问个人中心

**限制提示**:
- 点击需要登录的功能时，弹出登录引导弹窗
- 提示："登录后继续，解锁更多精彩功能"

---

### 2.1.2 普通用户（已登录）
**权限**:
- ✅ 所有游客权限
- ✅ 下单购买
- ✅ 收藏主理人
- ✅ 喜欢面包
- ✅ 管理订单
- ✅ 管理地址
- ✅ 编辑个人资料
- ✅ 问题反馈
- ✅ 申请成为主理人

---

### 2.1.3 主理人用户
**权限**:
- ✅ 所有普通用户权限
- ✅ 切换到主理人端
- ✅ 管理店铺信息
- ✅ 管理面包商品
- ✅ 处理用户订单
- ✅ 查看销售数据
- ✅ 查看成就排行

**特殊说明**:
- 主理人可以同时作为用户购买其他主理人的面包
- 不能购买自己的面包

---

## 2.2 角色切换

### 2.2.1 用户 → 主理人

**入口**:
1. 个人中心页面 → "成为主理人" 按钮
2. 个人中心页面 → "主理人" 按钮（已是主理人）

**流程**:
```
1. 点击"成为主理人"
2. 弹出申请表单弹窗
   - 上传头像
   - 输入店铺名称
   - 选择主营品类（多选）
   - 输入店铺简介
3. 提交审核
4. 审核通过后，显示"主理人"按钮
5. 点击"主理人"进入主理人端
```

**申请规则**:
- 店铺名称: 2-20个字符，不能重复
- 主营品类: 至少选择1个，最多5个
- 店铺简介: 10-200个字符
- 头像: 必须上传，支持 jpg/png，最大5MB

---

### 2.2.2 主理人 → 用户

**入口**:
- 主理人个人中心 → "切换用户" 按钮

**流程**:
```
1. 点击"切换用户"
2. Toast提示"已切换至用户模式"
3. 跳转到用户端首页
4. 底部导航切换为用户端导航
```

# 3. 用户端功能

## 3.1 首页 - 主理人列表

### 3.1.1 功能概述
- 展示附近的主理人
- 支持列表视图和地图视图切换
- 支持搜索和筛选
- 支持收藏主理人

---

### 3.1.2 顶部导航栏

#### 城市选择
**功能**:
- 显示当前定位城市
- 点击弹出城市选择器

**交互流程**:
```
1. 页面加载时，自动获取用户位置
2. 调用地理位置 API 获取城市信息
3. 显示城市名称（如：深圳）
4. 点击城市名称
5. 弹出城市选择器
   - 当前定位城市（带定位图标）
   - 常用城市列表
   - 搜索城市功能
6. 选择城市后
   - 更新城市显示
   - 重新加载主理人列表
   - Toast提示"已切换至xxx"
```

**权限处理**:
- 首次访问请求位置权限
- 拒绝授权: 默认显示"深圳"，允许手动选择
- 授权成功: 显示实际定位城市

---

#### 搜索功能
**功能**:
- 搜索主理人名称
- 搜索面包名称
- 搜索历史记录

**交互流程**:
```
1. 点击搜索框
2. 跳转到搜索页面
3. 显示搜索历史（最多10条）
4. 输入关键词
5. 实时显示搜索建议
   - 匹配的主理人名称
   - 匹配的面包名称
6. 点击搜索结果
   - 主理人: 跳转到详情页
   - 面包: 跳转到对应主理人详情页，自动定位到该面包
7. 搜索记录存储到本地
```

**搜索规则**:
- 最少输入1个字符开始搜索
- 支持模糊匹配
- 优先匹配主理人名称，其次面包名称
- 搜索结果按距离排序

---

### 3.1.3 视图切换

#### 列表视图
**默认视图**

**数据展示**:
- 主理人卡片列表
- 每个卡片显示：
  - 头像
  - 店铺名称
  - 距离
  - 主营品类
  - 3张面包缩略图
  - 收藏状态

**排序规则**:
1. 默认按距离从近到远
2. 支持切换排序：
   - 距离最近
   - 最受欢迎（收藏数）
   - 最新入驻

**分页加载**:
- 首次加载: 20条
- 触底加载更多: 每次20条
- 加载完毕显示: "没有更多了"

---

#### 地图视图
**切换显示**

**功能**:
- 显示主理人地理位置
- 地图标记点
- 点击标记显示简要信息
- 点击信息卡跳转详情页

**地图交互**:
```
1. 加载地图组件
2. 显示用户当前位置（蓝色点）
3. 显示主理人位置（面包图标标记）
4. 点击标记点
5. 底部弹出主理人卡片
   - 头像 + 名称
   - 距离 + 主营
   - 查看详情按钮
6. 点击卡片 → 跳转详情页
```

**地图控件**:
- 缩放控件（+ -）
- 定位按钮（回到当前位置）
- 地图/卫星视图切换

---

### 3.1.4 主理人卡片

#### 卡片信息
- **头像**: 56×56px 圆形
- **店铺名称**: 最多显示15个字符
- **营业状态**: 🟢营业中 / ⚪️已打烊
- **距离**: 动态计算（如：1.2km）
- **主营品类**: 最多显示3个，用"、"分隔
- **面包缩略图**: 最多3张
- **收藏按钮**: 心形图标 + 收藏数

#### 交互行为
**点击卡片**:
```
1. 点击卡片任意区域（除收藏按钮）
2. 页面跳转动画（右滑进入）
3. 进入主理人详情页
4. 埋点记录: baker_click
```

**点击收藏**:
```
1. 点击收藏图标
2. 判断登录状态
   - 未登录: 弹出登录提示
   - 已登录: 继续
3. 判断收藏状态
   - 未收藏: 
     - 图标填充红色
     - 收藏数 +1
     - 心跳动画
     - Toast: "收藏成功"
     - 埋点: bookmark_baker
   - 已收藏:
     - 图标变为空心灰色
     - 收藏数 -1
     - Toast: "已取消收藏"
4. 同步到服务器
5. 更新"我的收藏"列表
```

---

### 3.1.5 下拉刷新

**触发条件**:
- 在页面顶部下拉 > 80px

**刷新流程**:
```
1. 下拉超过阈值，显示"释放刷新"
2. 释放手指
3. 显示加载动画
4. 重新请求主理人列表
5. 更新数据
6. Toast提示"刷新成功"
7. 收起加载动画
```

**刷新内容**:
- 主理人列表数据
- 营业状态
- 距离信息
- 收藏状态

#### 面包卡片

**卡片信息**:
- 面包图片（120×120px）
- 面包名称
- 价格（¥XX/个）
- 简介（最多2行）
- 喜欢图标 + 喜欢数
- 数量选择器
- 销量标签（如：已售156份）
- 库存状态

**数量选择器**:
```
组件: [-] [数量] [+]

规则:
- 最小值: 0（0表示不购买）
- 最大值: 
  - 有库存限制: min(每日限量, 剩余库存)
  - 无库存限制: 99
- 步进值: 1

交互:
1. 点击 [+]
   - 数量 +1
   - 如果数量从 0 → 1，添加到购物车
   - 如果达到最大值，提示"已达购买上限"
   - 更新购物车总价
   - 按钮缩放动画

2. 点击 [-]
   - 数量 -1
   - 如果数量到达 0，从购物车移除
   - 更新购物车总价
   - 按钮缩放动画

3. 数量显示
   - 0: 显示灰色 "0"
   - >0: 显示橙色数字
```

**喜欢功能**:
```
1. 点击喜欢图标
2. 判断登录状态
   - 未登录: 弹出登录提示

   - 未喜欢 → 喜欢:
     - 图标变为红色实心
     - 喜欢数 +1
     - 心跳动画
     - Toast: "已添加到我的喜欢"
   - 喜欢 → 取消:
     - 图标变为灰色空心
     - 喜欢数 -1
     - Toast: "已取消喜欢"
4. 同步到服务器
5. 更新"我的喜欢"列表
6. 埋点: like_bread
```

**点击卡片**:
```
1. 点击面包卡片
2. 弹出面包详情弹窗
3. 显示:
   - 大图（全宽，4:3比例）
```

**显示规则**:

**交互行为**:

```
4. 可以在弹窗内调整数量
5. 点击清空:
```

**点击去结算**:
```

   - 已登录: 继续
3. 判断营业状态
   - 已打烊: 显示提示 "主理人已打烊，仍要下单吗？"
   - 营业中: 直接进入结算
4. 弹出结算弹窗
```

---

### 3.2.6 结算流程

#### 结算弹窗
**显示内容**:
1. 主理人信息
   - 头像 + 店铺名称
   
2. 订单明细
   - 商品列表（名称 × 数量 = 小计）
   - 小计金额

3. 备注输入框
   - placeholder: "给主理人留言（选填）"
   - 最多100字

4. 总价显示
   - 大号字体，橙色
   - "总计: ¥XX"

5. 确认下单按钮

**下单流程**:
```
1. 点击"确认下单"
2. 表单验证
   - 检查购物车是否为空
   - 检查商品库存
3. 生成订单
   - 订单号: 年月日 + 随机数
   - 订单状态: 待接单
   - 创建时间: 当前时间
4. 提交到服务器
5. 成功响应:
   - 关闭结算弹窗
   - 清空购物车
   - Toast: "下单成功"
   - 跳转到订单详情页
   - 埋点: place_order
6. 失败响应:
   - 显示错误提示
   - 不关闭弹窗
   - 允许重试
```

**异常处理**:
- 网络错误: "网络异常，请重试"
- 库存不足: "XXX库存不足，请调整数量"
- 已打烊: 显示确认提示

# 8. 异常处理

## 8.1 网络异常

### 无网络连接
```

1. 页面显示无网络提示
2. 显示重试按钮
3. 禁用需要网络的操作
4. 缓存用户操作（如编辑）
5. 网络恢复后自动重试
```

### 弱网环境
```
检测: 请求超时、响应慢

处理:
1. 增加加载提示时长
2. 显示"网络较慢"提示

4. 减少并发请求
5. 启用骨架屏
```
